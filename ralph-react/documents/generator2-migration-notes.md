# Generator 2 Migration Notes

Generator 2 is intended to replace the old generator with a simpler teacher-first workflow.
The old generator should not be copied feature-for-feature unless there is a specific user request.

## Deliberately Not Replicated

- Deck scaling: omitted because the Generator 2 layout is cleaner and does not need this control.
- Seat locking: omitted because feedback suggests it is confusing for users.
- Full metadata tables: omitted unless requested; users are not keen on heavy metadata entry.
- Mandatory generator-side auction entry: omitted. Player 2 can adjust auctions, so Generator 2 should allow blank auctions unless the user chooses automation.

## Still Worth Considering If Requested

- PBN import/edit in Generator 2.
- Copy PBN to clipboard or email PBN.
- Three-boards-per-page teacher PDF layout if the current two-board layout still feels too spacious.

## Current Direction

- Keep Generator 2 focused on board generation, review, quick manual entry, optional auction suggestions, PBN export, PDF aide memoire export, and direct handoff to Bridge Hand Player.
- Prefer simple controls and reversible choices.
- Let Bridge Hand Player remain the place for auction correction and play-through decisions.
